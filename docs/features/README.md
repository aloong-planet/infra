# Feature catalogue

What the infrastructure in this repository does today, as the people who use the sites and the owner who runs them see it. Each page describes one capability someone can point to, in terms anyone can check by using the sites or the repository's workflows: no file names, settings fields or architecture.

The catalogue describes only what works now. A capability gets a page when it ships, a page is rewritten in place when the behavior changes, and a page and its index line are removed when the capability is. History is in Git. Requirements, failure modes and decisions for the people changing the code are in `docs/specs/`, under the same slug as the page here.

| Feature | In one line |
|---|---|
| [Zone settings](zone-settings.md) | Browsers keep each aloongplanet.com site's files for as long as that site says, and the rule changes only through a reviewed change. |
